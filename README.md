# NumPy Statistics Project  

## Project Overview  
This project explores statistical analysis using Python and its scientific computing libraries. It uses a student scores dataset to examine scores across different study methods and practice statistical calculations and data analysis techniques.  
The project is developed in Jupyter Notebook and demonstrates the application of Python libraries for numerical computation, data manipulation, statistical analysis, and visualization.  

## Objectives  
- Load and explore a student scores dataset using pandas.  
- Perform numerical computations using NumPy.  
- Apply statistical methods using SciPy.  
- Analyze student score distributions and summary statistics.  
- Visualize data patterns using Matplotlib and Seaborn.  
- Explore score differences across study methods, where supported by the dataset.  

## Technologies Used  
- **Python** — Programming and data analysis  
- **NumPy** — Numerical computations and array operations  
- **pandas** — Data loading and manipulation  
- **Matplotlib** — Data visualization  
- **Seaborn** — Statistical visualizations  
- **SciPy** — Statistical functions and analysis  
- **Jupyter Notebook** — Interactive development environment  

## Dataset   
**File:** `student_scores.csv`  
The dataset contains the following columns, as shown in the notebook:  

| Column | Description |  
|---|---|
| student_id | Unique student identifier |  
| method | Study method associated with the score |  
| score | Student score |  

## Project Workflow  
1. Import the required Python libraries.  
2. Load the CSV dataset using pandas.  
3. Inspect the dataset structure and sample records.  
4. Perform relevant numerical and statistical computations.  
5. Analyze score distributions and study-method differences.  
6. Create visualizations to communicate the results.  
7. Summarize the findings based on the actual analysis.

## Key Findings  
-Measure of central tendency depicts the scores concentrated in range between 60 and 80.  
-Distribution curve is right-sided which means the data is negatively skewed.  
-Statistical test (ANOVA) implies there is mean differences in the sample.  
-ANOVA test rejects the null hypothesis, i.e teaching methods cannot affect the scores.
